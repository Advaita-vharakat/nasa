# Vioma- AI powered space research platform
<p>It is a space research platform integrating natural language processing, scientific data retrieval,
and data visualization to improve accessibility and understanding of complex space research.
It is an AI-powered space research platform that enables users to search scientific datasets, retrieve
relevant information using NASA APIs and the Perplexity API, and generate concise summaries of complex
research papers using natural language processing.
It has an AI-powered information retrieval module that processes user queries and generates contextual
insights with interactive data visualizations and graphical analytics using the Gemini API.</p>
